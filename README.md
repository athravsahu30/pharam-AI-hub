# 🏥 PharmaAI Hub

Welcome to **PharmaAI Hub**, a hybrid learning platform merging **Pharmaceutical Technology** with **Web Development** and **Artificial Intelligence**.

## 👨‍💻 About the Developer
Hi, I am **Athrav Sahu**, a 6th-semester B.Pharmacy student based in Jabalpur, Madhya Pradesh. I am passionate about exploring how technology and AI can revolutionize drug research, patient care, and pharmacy education.

## 🚀 Live Demo
**[Click here to view the live dashboard](https://athravsahu30.github.io/pharam-AI-hub/)**

## ✨ Current Features (Beta Phase)
* **Drug Explorer Interface**: A simulated search engine module for pharmaceutical drugs (e.g., Antibiotics, Anti-asthmatics).
* **Interactive UI**: Clean, responsive dashboard built with HTML, CSS, and Vanilla JavaScript.
* **Modular Structure**: Designed for future scalability and database integration.

## 🔮 Future Roadmap
As I expand my skills, this project will evolve into a full-fledged AI tool:
* **PharmaRAG**: AI-powered Pharmaceutical Research Assistant.
* **Pharmacokinetics Database**: Real-time retrieval of drug interactions and ADRs.
* **Smart Search**: Natural Language Processing for drug querying.
